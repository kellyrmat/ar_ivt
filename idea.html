A Persistent Homology and Machine Learning Pipeline for Subseasonal-to-Seasonal Forecasting of Atmospheric Rivers

1. Introduction

Subseasonal-to-Seasonal (S2S) atmospheric forecasting—spanning lead times of two weeks to two months—represents a critical gap in predictive capability. Standard Numerical Weather Prediction (NWP) relies on the integration of continuous partial differential equations (Navier-Stokes and Euler) over highly resolved spatial grids. At S2S timescales, these integrations are notoriously susceptible to chaotic error growth, where high-frequency local perturbations overwhelm the macroscopic signal of the climate regime.

Recent machine learning approaches have attempted to bypass NWP limits by applying Convolutional Weather Networks (CNNs) directly to these atmospheric grids. However, these models frequently overfit to local spatial noise and struggle to extract scale-invariant structural features. This paper introduces an alternative computational pipeline utilizing Topological Data Analysis (TDA)—specifically persistent homology. Rather than processing raw continuous grid data, we employ TDA as a rigorous feature extraction and noise-filtration step. By transforming scalar atmospheric fields into a sequence of cubical complexes, we compute discrete topological invariants (Betti numbers) that are robust to high-frequency grid noise. To make this topological data compatible with statistical learning, we map the resulting point clouds into a Banach space via Persistence Landscapes, perform linear dimensionality reduction, and ingest the latent vectors into a Random Forest regressor. This pipeline mechanically isolates the dominant structural features of atmospheric rivers (ARs) to provide a computationally stable feature space for S2S regression.

2. Data and Domain Discretization

The pipeline is validated using 44 years of NASA MERRA-2 reanalysis data (1980–2024). We extract daily averaged continuous scalar fields over a fixed spatial bounding box encompassing the Central Pacific and the North American West Coast. The domain is discretized as a 2D scalar array A of size N × M. We extract two distinct fields to separate the kinematic setup from the hydrologic target:

  • The Predictor (Z500): 500 hPa Geopotential Height anomalies, capturing macroscopic planetary wave propagation.
  • The Predictand (VIMH): Vertically Integrated Moist Helicity, isolating the specific scalar magnitude of the AR moisture transport.

3. Topological Filtration and Matrix Reduction

To extract structural features, we map the scalar grid A to a cubical complex, which serves as the discrete analog to a continuous manifold. We apply a superlevel set filtration. For a continuously decreasing threshold ν, we define a sequence of sub-complexes Kν consisting of all grid cells where the scalar value is greater than or equal to ν. This yields a nested sequence of topological spaces:

Kν0 ⊆ Kν1 ⊆ … ⊆ Kνn = K

To extract the topological invariants across this filtration, we construct a boundary matrix representing the connectivity of the cubical complex. By performing Gaussian elimination over the finite field ℤ2, we compute the kernel and image of the boundary operators to find the n-th homology groups. We track two specific Betti numbers:

  • β0: The rank of the 0-th homology group, counting the number of connected components.
  • β1: The rank of the 1-st homology group, counting the number of 1-dimensional homological cycles.

For every topological feature c, we record the threshold at which its homological class is generated (bi) and the threshold at which it merges with an older class (di). This produces a discrete set of 2D points (bi, di) known as a Persistence Diagram.

4. Functional Mapping and Dimensionality Reduction

Persistence Diagrams are unstructured point clouds. They lack a well-defined Hilbert or Banach space structure, meaning standard linear algebra and machine learning operations cannot be directly applied. To resolve this, we vectorize the topological data using Persistence Landscapes. We map each point (bi, di) to a set of piecewise linear functions, thereby embedding the discrete topological signature into a continuous Banach space Lp.

To capture the temporal evolution of the planetary wave over the S2S timeframe, we concatenate an 8-week (56-day) sliding window of these daily landscapes. Because this concatenation results in a high-dimensional feature space susceptible to the curse of dimensionality, we perform linear dimensionality reduction. We apply Singular Value Decomposition (SVD) to extract the principal components of the temporal landscape matrix, retaining the top k eigenvectors that cumulatively explain 95% of the variance.

5. Spatial Augmentation and Regression

Because persistent homology is translation-invariant, the PCA latent vector contains no geographic data—an inherent limitation when forecasting regional landfalls. To break this spatial degeneracy, we compute the Cartesian centroid coordinates (latitude and longitude) of the highest-persistence β0 components at each timestep. These coordinates are concatenated onto the PCA latent vector.

This final feature matrix is ingested into an ensemble of decision trees (a Random Forest regressor) optimized to minimize Mean Squared Error (MSE). The model maps the 8-week Z500 topological trajectory to the future maximum persistence of the VIMH field, providing a quantitative prediction of AR intensity.

6. Validation and Conclusion

The pipeline was tested against the 2022–2023 sequence of Sierra Nevada ARs. During execution on the MERRA-2 data, the superlevel set filtration successfully segmented the continuous VIMH fields into singular β0 connected components. The moment of AR landfall—where mountain-induced drag physically fragments the moisture flow—was computationally identified as the rapid termination (death) of the dominant β0 class.

By mechanically converting continuous atmospheric grids into cubical complexes, applying algebraic matrix reduction, embedding the outputs into a Banach space, and compressing the variance, this pipeline demonstrates a mathematically rigorous method for S2S feature extraction. It effectively bypasses the continuous integration errors of standard NWP, providing a stable, discrete predictive framework for extreme weather regimes.
